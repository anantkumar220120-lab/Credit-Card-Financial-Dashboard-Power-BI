# Credit-Card-Financial-Dashboard-Power-BI
Credit Card Financial Dashboard built using Power BI to analyze customer behavior, transaction trends, revenue, interest earnings, and key business KPIs through interactive visualizations and data-driven insights.

Credit Card Financial Dashboard | Power BI
---> About the Project

This project is an interactive Power BI dashboard created to analyze credit card customer and transaction data. The goal was to convert raw data into meaningful insights that can help businesses understand customer behavior, monitor financial performance, and make informed decisions.

Through this dashboard, users can easily track important metrics such as revenue, transaction volume, interest earned, customer demographics, and spending patterns.

 What I Did

* Cleaned and transformed raw data using Power Query.
* Built relationships between customer and transaction tables.
* Created DAX measures to calculate important business KPIs.
* Designed interactive dashboards with filters and visualizations.
* Analyzed customer spending behavior across different segments.
* Generated insights to help understand business performance.

 Key Metrics Tracked

* Total Revenue
* Total Transaction Amount
* Total Interest Earned
* Transaction Count
* Weekly Revenue Growth
* Customer Segmentation Analysis

Dashboard Insights

The dashboard helps answer business questions such as:

* Which customer groups generate the highest revenue?
* Which credit card category performs the best?
* How are transactions changing over time?
* Which regions contribute the most revenue?
* What are the weekly business growth trends?
